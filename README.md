# SE-2530-BuilderPattern-Aquarium
# Aquarium Builder Pattern
This project demonstrates the Builder design pattern to construct different types of aquariums.
## Product
The product is an `Aquarium` class.

## How to build
Use `ReefMarineBuilder` for saltwater tanks or `PlantedFreshwaterBuilder` for freshwater setups.
An `AquariumDirector` is available for standard configurations.

## How to run
Run the `Main.java` class to see the demonstration.
